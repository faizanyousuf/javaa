What is Collection

A collection is simply an object that represents a group of objects, known as its elements

What is Collection Framework

It provides a set of interfaces and classes that help in managing groups of object


the Collection interface is the root interface of the java Collection Framwork. It is the most basic interface that defines a group of objects known as elements. The collection interface is a part of java.util package, and it is a parent interface that is extended by other interfaces like List, set, and Queue

Since Collection is an interface, it can't be instantiated directly; rather it provides a blueprint for the basic operations that are common to all collections.
