List Interface

The list interface in java is a part of the java.util package and is a sub-interface of the collection interface. It provides a way to store an Ordered Collection of elements (Known as sequence) Lists allow for precise control over where elements are inserted and can contain duplicate elements

The list inteface is implemented by several classes in the java collection framework, such as Arraylist,LindedList,Vector, and Stack

Key features of the list Interface

,
  • Order Preservation
  • index-Based Access
  • Allows Duplicates
