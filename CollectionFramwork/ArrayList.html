ArrayList

ArrayList is a resizable array implementation of the list interface. unlike arrays in java, which have a fixed size, an arraylist can change its size dynamically as elements are added, removed. this flexibiliy makes it a popular choice when the number of elements in a list isn't known in advance

Syntax

ArrayList arr1 = new ArrayList<>();
or
List list = new ArrayList<>();

Level 1 -- Foundation

  • Arraylist is a class
  • It implements List
  • List extends Collection
  • It maintains insertion order
  • Duplicates are allowed
  • It uses zero-based indexing
  • it is dynamically resizable
  • it internally uses an array(Object[] in OpenJDK)

Level 2 -- Master the Core Methods

  • Adding:
    • list.add(10)
    • list.add(1,20)
    • list.addAll(other);
    • list.addAll(1,other);
  • Accessing:
    • List.get(index)
    • list.size();
    • list.isEmpty();
  • Updating:
    • list.set(2,100); // set --> replace
  • Removing:
    • list.remove(0); //index
    • list.remove(Integer.valueOf(20);// object
    • list.removeIf(x -> x%2 == 0); //condition based remove
    • list.clear();
     Note: You must master list.remove(index) vs List.remove(Object[]);
  • Searching:
    • list.contains(object);
    • list.indexOf(object);
    • list.lastIndexOf(object);
