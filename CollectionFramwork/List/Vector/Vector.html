Java Vector

the Vector class is an implementation of the list interface that allows us to create resizable-arrays similar to arraylist

  • Vector vs ArrayList
    • In java, both Arraylist and Vector implements the list imterface and provides the same functionalities. However, there exist some differences between them.
    • The vector class Synchronizes each individual operation. this means whenever we want to perform some operation on vectors, the vector class automatically applies a lock to that operation.
    • It is because when one thread is accessing a vector, and at the same time another thread tries to access it , and exception calles concurrentModificationException is generated.Hence this continuos use of locks for each operation makes vectors less efficient.
    • However in arraylist methods are not synchronized. Instead it uses the Collections.synchronizedList() method that synchronizes the list as a whole.
    • It is recommended to use the arraylist in place of vector because vectors are less efficient.
