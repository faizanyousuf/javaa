Linked List

The linked list class of the java collections framework provides the functionality of the linked list data structure (doubly Linkedlist)

  • Each element in a linked list is known as a node. It consists of 2 fields:
  • Prev-stores and address of the previous element in the ist. It is nul for the first element
  • Next-stores an address of the next element in the list. It is null for the last element
  • Data- stores the actual data
